关于 像素画板
🎨 像素画板

一个零依赖、单文件的像素绘图小工具，界面与交互借鉴经典像素软件。

功能多图层（增删/排序/可见性/重命名/不透明度/混合模式/缩略图）、画笔 / 橡皮擦 / 油漆桶 / 吸管、撤销重做、以鼠标为中心的缩放与平滑平移、透明背景 PNG 导出、可配置首选项、中日英界面。

快捷键B / E / G / I 切换工具 · Ctrl+Z / Ctrl+Y 撤销重做 · Ctrl+[ / Ctrl+] 调整图层顺序 · Ctrl+Shift+N 新建图层 · 滚轮缩放 · 空格或中键拖拽平移 · Ctrl+0 适配视图

纯 HTML + CSS + JavaScript，无任何外部依赖，双击即可离线运行。

界面字体：Fusion Pixel Font（SIL OFL 1.1 · © TakWolf 及贡献者）

Q&A
Q1. 快捷键在哪里查看或修改？
打开 设置 → 快捷键，可查看全部快捷键，点击“更改”后直接按下新组合即可自定义。
Q2. 如何撤销或重做？
默认 Ctrl+Z 撤销、Ctrl+Y 重做（也可在设置中自定义其他按键）。
Q3. 如何保存或打开工程？
使用 文件 → 导出工程 保存为 .AIPSD 工程文件，文件 → 打开工程 载入；文件 → 导出 PNG 可导出图片。
Q4. 图层文件夹怎么使用？
新建文件夹后，把图层拖到文件夹行上即可移入；文件夹行可拖拽排序、折叠、单独控制可见性，文件夹内图层的合成顺序不变。
Q5. 如何缩放或平移画布？
滚轮以鼠标为中心缩放；按住空格或中键拖拽平移；Ctrl+0 适配视图，Ctrl+1 回到 100%。
Q6. 如何切换界面语言或主题？
打开 设置 → 外观，可切换 中文/日本語/English 界面与深色/亮色主题。
Q7. 移动工具和形状工具怎么用？
选择「移动」工具（V）后在选区内拖拽即可剪切移动选区内容；「形状」工具（U）拖拽绘制矩形/圆形，用工具栏下方按钮切换 方/圆 与 填充/描边（描边粗细随顶部「大小」）。
Q8. 选区如何移动或取消？
用「选择」工具拖拽选区内部（非边缘）移动选框，拖边缘或外部重新框选；Ctrl+A 全选、Ctrl+D 取消，点击画布外空白也可取消（可在设置中开关）。
Q9. 如何调节画笔/橡皮擦粗细？
顶部工具栏的「大小」滑块控制画笔与橡皮擦的粗细（1–16 格）。
Q10. 如何吸取画布上的颜色？
用「吸管」工具（I）点击画布取色；或点颜色面板的「从画布取色」按钮后点画布取色，取色后自动回到原工具。
