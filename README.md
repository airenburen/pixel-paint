# 像素画板 (Pixel Paint)

单文件风格的像素画编辑器，支持图层、图层文件夹、剪切蒙版、混合模式、选区、移动/形状工具、快捷键自定义、多语言与深/亮主题，可导出 `.AIPSD` 工程文件与 PNG 图片。

## 使用

直接打开 `index.html` 即可（完全离线，无需构建；字体已内嵌于本地 `assets/`）。

> 两种形态：
> - **拆分版**（本目录）：`index.html` + `styles.css` + `app.js` + `assets/`，便于维护
> - **单文件版**：`standalone/index.html`，全部样式/脚本/字体内联在单个文件，便于分发或另存

## 目录结构

```
pixel-board/
├── index.html   # 入口（外链样式与脚本）
├── styles.css   # 全部样式（含像素风字体引用）
├── app.js       # 全部逻辑
├── assets/
│   └── fusion-pixel.woff2   # Fusion Pixel 像素字体（本地离线）
└── standalone/
    └── index.html           # 单文件版（样式/脚本/字体全部内联）
```

## 功能特性

- 图层：新建/复制/删除/重命名/排序/锁定/可见性，拖拽排序带插入位置提示
- 图层文件夹：新建、折叠、独立可见性、与图层一致的拖拽排序
- 剪切蒙版（PS 相邻成组语义）与混合模式（normal / multiply / screen 等）
- 选区：矩形选区、移动蓝框（点内部）、移动工具剪切移动内容、全选/取消
- 工具：画笔、橡皮擦（粗细可调）、油漆桶、吸管、移动、形状（方/圆、填充/描边）
- 颜色：色轮 + RGB 模式、透明度、`#RRGGBBAA` 色值、预设色（16 位像素色等风格）、从画布取色
- 图像调整：色相 / 亮度 / 对比度 / 饱和度（作用于选区或整层）
- 视图：滚轮缩放、空格/中键平移、平滑插值、适配视图
- 撤销/重做（步数可设）、快捷键自定义（设置内录制）
- 多语言：中文 / 日本語 / English；深色 / 亮色主题
- 导出：`.AIPSD` 工程文件（含图层、文件夹、混合模式与可选设置）、PNG 图片
